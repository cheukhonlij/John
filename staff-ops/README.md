# TODAY'S FOOD LAB · 員工營運系統

俾全體員工用嘅營運系統，同發票系統（repo 根目錄）**完全分開**：獨立 build、獨立部署、獨立資料。
呢度冇客戶價錢、冇貨品售價、冇人工資料，所以可以放心開俾所有同事用。

## 功能

| 頁面 | 內容 |
| --- | --- |
| 今日 | 今日返工、放假、未完成工作、要補貨、聽日更表、下個法定假日 |
| 排更 | 每週更表、常用更份、複製上週、整週排更、列印；兼職顯示近 4 星期工時（468 規則） |
| 每日流程 | 按時間嘅工作清單，打剔記錄邊個幾點做；連結相關 SOP；可列印 |
| 倉存／入貨落貨 | 現有存貨、安全存量提示、入貨（批次／到期日）、落貨、損耗、盤點、紀錄 |
| 假期 | 申請及批核、年假／病假結餘（按《僱傭條例》計）、2026–2027 法定假日 |
| SOP | 標準作業程序，可搜尋、編輯、列印 |
| 員工 | 全職／兼職、入職日期、休息日、公司額外年假 |

## 員工模式 vs 主管模式

- **員工**（預設）：睇更表、打剔流程、記錄入貨／落貨／盤點、申請假期、睇 SOP。
- **主管模式**（頁頂「主管模式」，預設密碼 `1234`，請喺「設定」改）：排更、批假、改 SOP、改流程、改貨品清單、刪除紀錄、備份。

> 主管密碼只係一個簡單嘅鎖，防止同事誤改，**唔係正式保安**。

## 運行

```bash
cd staff-ops
bun install        # 或 npm install
bun run dev        # 開發：http://localhost:3001
bun run build      # 輸出 dist/，可以放上任何靜態網頁寄存（例如 Firebase Hosting、Netlify、Cloudflare Pages）
bun run lint       # TypeScript 檢查
```

## 重要：資料儲存

而家所有資料儲存喺**該部機嘅瀏覽器**（localStorage）。即係：

- 適合一部共用機（例如工場嘅平板或電腦）。
- 唔同手機／電腦之間**唔會同步**。
- 清除瀏覽器資料會清走紀錄 —— 請定期喺「設定 → 匯出備份」。

如果要每個同事用自己手機睇同一份更表，下一步需要加一個雲端資料庫（例如 Firebase／Supabase）同員工登入。

## 計算規則（只供參考，以勞工處為準）

- 年假：做滿第 1、2 年各 7 日，之後每年加 1 日，最多 14 日。
- 有薪病假：首 12 個月每月累積 2 日，之後每月 4 日，最多 120 日。
- 連續性合約（2026 年 1 月 18 日起）：每週 17 小時或每 4 星期合共 68 小時。
- 法定假日：2026、2027 年各 15 日（`src/data/defaults.ts`，可喺「假期 → 法定假日」修改）。
